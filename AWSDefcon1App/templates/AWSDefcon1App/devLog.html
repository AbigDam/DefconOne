Update: 2026-01-01 10:00 AM

  • Feature Updates (Summary)
    • Espionage no longer requires war
    • Any nation can now make an alliance
    • Error messages avoid changing page
    • Map is compressed
    • Dev-Log section added
    • Various small bug/ui fixes

  • Bug Fixes
    • Refreshes will now only occur in the lobby that triggered the refresh, not all other lobbies
    • Surrendering, or otherwise losing will now longer trigger an error message
    • Espionage is now possible without declaring war
    • Tile mappings will only load when the 'Territory Select' is selected, trading faster load pages for slightly delayed click response
    • Guest single player no longer has the 'all other nations' restricting guests to the base 11 countries
  • UI Changes
    • Available nations will now appear at the top of join lists in lobbies
    • Verticle bar added to make attack modes more clear
    • Map compressed for faster load times
    • White box around "declare war" button is removed
    • The map is now centered instead of a few pixels to the left
  • Error Message Updates
    The following error messages replaced with alerts to remove unnecissary page changes
    • 0 Requests/Battles/Points Left
    • Attacking a nation with no border to you
    • Attacking a state you can't access that turn
    • Navally invading a non-costal state
    • Navally invading a nation with no coast
      • Additionally, The following error messages removed by disabling the functionality that caused them
    • Declaring war on an ally disabled
    • Offering an alliance to an ally disabled
    • Interacting with the "no nation selected" nation disabled
    • Interacting with the "no nation selected" nation disabled
  • Alliance System Updates
    Alliance related bugs fixed
    • Nations are now less likely to accept alliances
    • If a minor nations requests alliance to a bot major the minor will join the majors team
    • All nations can now offer alliances and create alliances
